# 🐱 MiAU.exe — React

Uma evolução do projeto **MiAU.exe**, agora desenvolvido com **React**, explorando componentes, estados, props e navegação entre páginas enquanto mantém a identidade visual retrô e pixelada da comunidade felina.

## ✨ Sobre o projeto

O **MiAU.exe** é uma comunidade fictícia para humanos escolhidos por gatos. 🐾

Nesta versão, a aplicação foi reconstruída utilizando React e dividida em diferentes componentes e páginas, permitindo uma estrutura mais organizada, reutilizável e dinâmica.

## ⚙️ Funcionalidades

* 🏠 Página inicial
* 🐾 Lista dinâmica de membros
* ➕ Adição de novos membros
* 🗑️ Remoção de membros
* 🔢 Contagem automática de membros
* 🧭 Navegação entre páginas
* 🚫 Página personalizada de erro 404
* 📱 Interface responsiva
* 🎮 Identidade visual inspirada em pixel art

## 🧠 Conceitos praticados

## 🚀 Como executar

Clone o repositório:

```bash
git clone [URL_DO_REPOSITORIO](https://github.com/LauraFMP/React-Componentes-Hooks-e-Rotas...com-gatinhos)
```

Entre na pasta do projeto:

```bash
cd React-Componentes-Hooks-e-Rotas...com-gatinhos
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois, abra no navegador o endereço exibido pelo Vite no terminal.

O projeto foi desenvolvido para praticar os fundamentos do **React**, entendendo como criar componentes reutilizáveis, trabalhar com estados, renderizar listas dinamicamente e implementar navegação utilizando o React Router.
